# 🔄 Metric/Imperial Unit Converter

A sleek and interactive unit conversion tool that makes converting between metric and imperial units a breeze! ✨

## 🎯 What it does

Convert between:
- **Length**: Meters ↔ Feet
- **Volume**: Liters ↔ Gallons  
- **Mass**: Kilograms ↔ Pounds
